# Proyecto-RappiPlus-de-datos-a-decisiones-de-negocio
Proyecto de análisis de negocio para RappiPlus, desarrollado con Python, SQL y herramientas de BI. Evalúa la calidad de datos, rentabilidad, marketing, conversión del funnel, retención de usuarios y resultados de pruebas A/B para generar insights y recomendaciones accionables.
